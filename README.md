# Hide Ownership Warning

You have this weird ownership message for some mysterious reason. This mod removes it. Don't ask questions.

## What it does

Hides only the file integrity watermark (`file_integrity_watermark`) in the main menu.

No gameplay change. No DLC list change. UI only.

## Install

1. Copy `hide_ownership_warning.mod` and the `hide_ownership_warning` folder into `Documents/Paradox Interactive/Hearts of Iron IV/mod/`.
2. Enable it in the Paradox Launcher playset.
3. Play.

## Compatibility

- HOI4 1.19.*
- Safe to add or remove at any time.
